# InternetStore — Десктопный интернет-магазин

Десктопное приложение для автоматизации процессов розничной торговли: ведение каталога товаров, управление корзиной, оформление заказов, многоуровневая ролевая модель доступа и панель администрирования ассортимента.

Проект разработан в рамках учебного проектирования по специальности 09.02.07 «Информационные системы и программирование».


## Стек технологий

* **Язык разработки:** C# (.NET)
* **Пользовательский интерфейс:** WPF
* **Архитектурный паттерн:** MVVM (Model-View-ViewModel)
* **СУБД:** Microsoft SQL Server
* **ORM:** Entity Framework Core
* **Среда разработки:** Visual Studio
* **Методологии и планирование:** Диаграмма Ганта, разработка эксплуатационной документации (руководство оператора и системного программиста)


## Архитектура приложения и реализация MVVM

Приложение спроектировано в строгом соответствии с шаблоном MVVM с полным разделением пользовательского интерфейса (XAML) и прикладной логики:

* **Базовый класс ViewModelBase:** реализует интерфейс `INotifyPropertyChanged` для оповещения слоя представления об изменениях свойств модели представления.
* **Класс RelayCommand:** собственная реализация интерфейса `ICommand`, инкапсулирующая вызовы `Action` / `Predicate<object>` для обработки событий пользовательского ввода через механизм биндингов (включая синхронные и асинхронные команды).
* **Слой данных (Data Access Layer):** взаимодействие с БД организовано через Entity Framework Core с использованием типизированного контекста `DbContext`. Представления не имеют прямых зависимостей от базы данных.


## Ролевая модель

В системе разграничены зоны ответственности на основе ролевой модели:

1. **Гость:**
   * Просмотр витрины товаров с фильтрацией по категориям, стоимости и наименованию.
   * Просмотр детальной карточки товара.
   * Регистрация нового аккаунта и авторизация.

2. **Покупатель (Клиент):**
   * Формирование корзины с динамическим пересчетом количества позиций и общей суммы.
   * Оформление заказа с выбором способа получения.
   * Просмотр истории собственных заказов и отслеживание статусов выполнения в личном кабинете.

3. **Менеджер:**
   * Просмотр общего реестра заказов покупателей.
   * Изменение статусов обработки, оплаты и доставки заказов.

4. **Администратор:**
   * Полное CRUD-управление каталогом товаров (добавление, редактирование параметров, списание/архивация).
   * Управление категориями товаров и прайс-листом.
   * Администрирование учетных записей пользователей и назначение ролей.


## Структура базы данных

Реляционная база данных нормализована и включает следующие сущности:

* `User` — учетные записи пользователей (логин, хэш пароля, ФИО, телефон, email).
* `Role` — справочник системных ролей (Гость, Клиент, Менеджер, Администратор).
* `Product` — номенклатура товаров (наименование, описание, цена, количество на складе, изображение).
* `Category` — категории товаров.
* `Order` — заголовок заказа (дата создания, клиент, итоговая сумма, текущий статус).
* `OrderStatus` — справочник статусов заказа (Новый, В обработке, Оплачен, Доставлен, Отменен).
* `OrderItem` — связующая таблица состава заказа с фиксацией цены товара на момент покупки (M:M).
* `CartItem` — временное хранилище позиций корзины авторизованного пользователя.


## Валидация данных и безопасность

* **Валидация учетных данных:** механизм валидации полей ввода при регистрации (проверка длины логина и пароля, обязательность полей, проверка формата электронной почты и номера телефона).
* **Контроль уникальности:** проверка на отсутствие дублирования логина/email перед фиксацией транзакции в БД.
* **Ролевой доступ к интерфейсу:** динамическое сокрытие и блокировка управляющих элементов (кнопок администрирования, редактирования цен, доступа к заказам) на основе прав текущего авторизованного пользователя.
* **Целостность данных:** использование внешних ключей (Foreign Keys) и транзакций при создании заказа и списании остатков товаров со склада.
